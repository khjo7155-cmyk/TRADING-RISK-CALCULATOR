Model notes

Streak drawdown = 1 − (1 − risk)^k

Expectancy (R) = win rate × average win (R) − loss rate

Recovery return = drawdown ÷ (1 − drawdown)

The sample-streak probability uses dynamic programming to estimate at least one run of the selected length, rather than the probability of one preselected sequence.
